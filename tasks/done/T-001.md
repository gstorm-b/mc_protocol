## Review verdict  *(reviewer writes — skipped only if Class says so)*

- Findings (severity · file:line · what/why):
  1. **should-fix** · `docs/spec/SPEC-build-packaging.md:73` — the "Everything,
     one command" `check.sh` example still reads
     `scripts/check.sh /opt/Qt/6.7.2/mingw_64 # Git Bash, MinGW`. `/opt/Qt/...`
     is the Linux Qt-installer path convention; it is exactly the "Linux Qt
     path" the Plan's step 1 says this hunk must not be (only the trailing
     directory name and the comment were changed, `gcc_64` → `mingw_64`, the
     `/opt/Qt` root was left as-is). Every other Qt path in this project
     (`docs/spec/SPEC-build-packaging.md:72`, `project-context.md`,
     `tasks/todo.md`) is `C:/Qt/...`, matching the actual Windows-only install
     this spec now documents. A reader following this example on Windows in
     Git Bash gets a path that resolves nowhere. Fix: change the root to a
     Windows-style path, e.g. `C:/Qt/6.7.2/mingw_64` (consistent with the
     `check.ps1` line immediately above it).
