## Dev notes  *(developer writes)*

- Files changed (new unless marked; nothing under `include/` or `src/`):
  - `tools/mc_workbench/config_binding.{h,cpp}` (core) — `ConfigBinding`: qpb tree bound to `McDeviceConfig`. Built from `toJson()`'s key names (`fields()` table: 52 fields + `subscriptions` text). Each edit goes through a qpb validator: candidate = `toJson()` of the applied config with the one field replaced, `fromJson()` then `validate()`; a refusal returns the library's message plus the path it names (`TCP port is 0 (transport.tcp.port)`), qpb keeps the old value, `rejected()` is emitted. An accepted edit updates `config()` and emits `configChanged()`. Frame family change falls back to that family's defaults (`frame3C()` ...) when the old values do not fit. `setEditable()` greys the grid while connected.
  - `tools/mc_workbench/console_model.{h,cpp}` (core) — `ConsoleModel` (token / request id / outcome correlation in either arrival order, bounded to 1000 rows) and `parseWordList` / `parseBitList`.
  - `tools/mc_workbench/point_table_model.{h,cpp}` (ui) — `PointTableModel`: one row per subscribed point from `ValueBatch` snapshots, changed-value highlight (1.5 s, from snapshot diff and from `changes`), Stale marking, trend check box column, `trendSample` signal.
  - `tools/mc_workbench/trend_widget.{h,cpp}` (ui) — `TrendWidget`: QPainter line chart, ring of 4096 samples per series, sliding window, auto value axis, legend; no Qt Charts.
  - `tools/mc_workbench/device_tab.{h,cpp}` (ui) — `DeviceTab` (grid, Connect/Disconnect, link state, fault line, refusal line, subscribe/remove at run time, points table, trend, console) on a `DeviceHost`; `DevicePane` (the Devices dock content: "New device" button, closable tabs).
  - `tools/mc_workbench/main_window.{h,cpp}` (shared, small additive edits) — the Devices dock now holds a `DevicePane`; `devicePane()`; File > "New device tab" (Ctrl+T).
  - `tools/mc_workbench/CMakeLists.txt`, `tools/mc_workbench/mc_workbench.pri` (shared, additive) — the new sources.
  - `tests/gui/tst_gui_device_tab.cpp` — 13 cases (`DeviceTabTest`), `tests/gui/gui_suites.h` + `tests/gui/gui_tests_main.cpp` (shared, additive: `makeDeviceTabSuite`), `tests/CMakeLists.txt`, `tests/qmake/mc_workbench_tests.pro` (shared, additive: the new test source).
  - `device_runner.*` / `device_host.*` not touched (the T-068 API was enough).
- Deviations from plan (+ reason):
