## Plan  *(leader writes; Gate 1 approves)*

- **Goal:** `SPEC-gui-tool.md` HIL runner row and Boundaries (amended 2026-10-04): the "confirm
  without typing" box is offered only for a loopback profile (TCP host in `127.0.0.0/8`, `::1`,
  `localhost`, as `isLoopbackHost()`) whose run has no `readOnly` frames. Any other profile —
  another host or any COM port — always needs the typed profile id.
- **Approach:** `tools/mc_workbench/hil_prepare.*` (`mustTypeProfileId` / `confirmationAccepted`
  take the profile's transport), `hil_confirm_dialog.*` (box hidden unless allowed), and the
  runner-thread re-check in `hil_runner.cpp` (the run refuses `skipTyping` for a non-loopback or
  COM profile even if the dialog were bypassed). The CLI `hil_capture` and its `--yes` are unchanged.
- **Acceptance criteria:** GUI-07 (amended) green: truth table over {loopback TCP, other TCP host,
  COM} × {readOnly frames, none} × {typed id right / wrong / skip}; the runner thread refuses
  skipTyping for non-loopback and COM with 0 connections to a listener; the T-072 tests still pass.
- **Gate 1 approval:** 2026-10-04 — leader, under the owner's delegation for the Phase 8 follow-ups (`rules.md`); spec text approved by the owner the same day. Gate 2: leader, one commit for T-075…T-077 after tester and reviewer pass.
