## Plan  *(leader writes; Gate 1 approves)*

- **Goal:** two small library changes the owner decided on 2026-10-03.
- **Owner quote:** "maxConsecutiveLinkErrors mặc định là 3, validate từ chối giá trị 0. Viết thêm
  function đọc số byte rác, chủ yếu hỗ trợ debug trace."
- **Approach:**
  1. **core-session:** `SessionConfig::validate()` rejects `maxConsecutiveLinkErrors == 0` with
     `ErrorCode::InvalidConfig` (message naming the field), on every frame (the field only acts on
     serial, but a 0 is a configuration error everywhere). The default stays 3. Update the field's
     doc comment in `include/mc/core/session.h` (doc only; owner-approved public header change) and
     remove any code or comment that treats 0 as 1. Spec already amended
     (`SPEC-core-session.md` field line).
  2. **mock-plc:** `uint64_t MockPlc::skippedBytes() const` — serial bytes skipped before a start
     byte, and bytes of a run that cannot start a frame (as the decoder already skips them), counted
     per instance; `clearLog()` resets it; Ethernet frames leave it unchanged. Each skip is logged
     at `Trace` with the running count (debug trace). Declared in `include/mc/mock/mock_plc.h`
     after `eotCount()` with a Doxygen comment (owner-approved public header change). Spec already
     amended (`SPEC-mock-plc.md` observation block and "Serial reception").
  3. Callers: `McDeviceConfig` JSON / `hil_capture` profiles that might carry 0 — check that a 0
     now fails with a clear error (no silent change); example profiles keep 3.
- **Files expected to change:** `src/core/session/session.cpp`, `include/mc/core/session.h`
  (doc comment), `tests/core/session/*` (new cases), `src/mock/*` (counter + trace),
  `include/mc/mock/mock_plc.h`, `tests/mock/*` (new cases), `CHANGELOG.md`.
- **Acceptance criteria:**
  1. `Session::create()` with `maxConsecutiveLinkErrors = 0` returns `InvalidConfig` (3E and 3C);
     1 and 255 are accepted; the default is 3 (test pins the literal).
  2. `skippedBytes()` counts exactly the junk bytes on every serial family/format (e.g. 3 bytes of
     `JunkPrefix` → 3; junk split over several `feed()` calls; an unframable run); `clearLog()`
     resets it; an Ethernet session leaves it at 0. Hand literals, not values from the code.
  3. A `Trace` log line is written per skip with the count (test with the mock's log sink).
  4. Mutants: accept 0; never increment; not reset by `clearLog()` — each fails a test.
  5. MSVC and MinGW all labels green; qmake case lists equal; coverage bars kept.
- **Verification commands:** the MSVC daily loop of `build-env.md` (all labels incl. `hil_tool`,
  `replay`), MinGW, qmake MSVC.
- **Gate 1 approval:** 2026-10-03 — leader; the change itself is the owner's decision. Gate 2:
  **owner** (Phase 7 delegation has ended; the leader asks before committing).
