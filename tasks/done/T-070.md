- Known limits (for the Checkpoint H reviewer):
  - Multi-client TCP: all clients of one mock share one `MockPlc` byte parser. Each chunk a client sends is fed whole and the responses it yields go back to that client. If one request is split across two TCP segments and another client's chunk arrives between them, the two partial frames interleave and both requests are corrupted. `McDevice` sends one short request per write on loopback, so this has not been seen, but it is not prevented. A client that disconnects in the middle of a frame leaves a partial frame in the parser (as T-068 did for the next client). Fixing it needs a per-client parser or a way to read the parser state, i.e. a library change.
  - The memory image cannot be copied out of a `MockPlc`: a changed frame or error code empties memory and faults.
- Notes for the tester:
  - Env notes for `build-env.md`: `QAbstractItemView::state()` is protected (detect an open cell editor with `viewport()->findChild<QLineEdit*>()`); `QColor` is QtGui, not available in `mc_workbench_core` (Core + Network only): use roles other than `ForegroundRole` in core models; `mc::McProtocol(cfg).encode(Request)` is the way to build a well-formed frame in a test; a mock in a QtTest runs fine on `127.0.0.1` with `listen(0)` for the port.
  - Where things live: `MockRunner`/`MockPlc`/`QTcpServer`/`QSerialPort` on the runner thread; `MockTab` holds only a `MockHost`, qpb model and widgets. `MockTab::~MockTab` deletes the host first (joins within the 3 s bound), then the widgets. `MockPane::closeMock` deletes the tab (blocks up to the bound while the thread stops).
  - COM: the mock opens the first port of the pair, the device side the second; the test also checks that the port is free again after `stopListening`. The pair must not be used by any other process meanwhile (lock `mc_serial_pair` holds inside one ctest only).
  - Mutation ideas that should fail a test: skip `corruptNext`/`muteNext` in the runner (`corruptNextDamages...`, `muteNextSwallows...`); drop `m_plc->clearLog()` in `flushNow` (burst totals and the bounded batch); allow `reconfigure` while serving; make the memory editor ignore the `Octal` notation; feed only the newest client (GUI-02 `twoClients`).
  - Not covered by an automated test: the interactive look of the tab (docking, qpb grid layout, auto refresh while visible), serving a COM port with a non-default line (7E1 only), the 32-client cap.
