- Notes for the tester:
  - `int16At`/`int32At` convert an unsigned bit pattern to signed via `static_cast`, which is
    implementation-defined (not UB) before C++20 rather than guaranteed two's complement; MSVC,
    GCC and Clang all define it as two's complement wraparound in practice, but this is worth
    knowing if a test ever seems to disagree with a hand-computed two's-complement value on a
    compiler not in that list.
  - `stringAt()`'s contract is "characters actually written" (capped by `capacity`), not the
    snprintf-style "characters that would have been written" `formatDevice()` (T-007) uses — a
    genuinely different convention within the same codebase, matching the module spec's own
    wording ("Returns characters written") rather than an assumption of consistency with
    `formatDevice`.
  - `wordsToBits()`/`bitsToWords()` and the `A`-family cell of `Write1402WordSub0000` in T-009's
    limits work are unrelated despite both mentioning "words"/"bits" — no shared code, just
    adjacent vocabulary in the spec.
  - CNV-06 also exercises `bitsToWords()` as an inverse-direction round trip of the same PRIM-15
    example, even though PRIM-15 itself (spec §9.2) only names the forward direction
    (`words_to_bits`); this is additional coverage beyond the letter of PRIM-15, not a substitute
    for it.
