## Plan  *(leader writes; Gate 1 approves)*

- **Goal:** QnA 0401 / 1401 request data and response-data decoding, written
  once against the field codec and shared later by 3E and 3C.
- **Approach:** per the module spec's "Commands" and "Internal design": no
  ASCII/Binary branch inside command code except device encoding; the 0403 /
  1402 tables present but not reachable in v1; response decoding writes the
  normalized payload of the module spec's "Payload contract" (bits one byte
  per point or packed LSB-first; words little-endian; words on a bit device
  as raw words).
- **Files expected to change:** `src/core/protocol/command_qna.h`,
  `src/core/protocol/command_qna.cpp`, `src/CMakeLists.txt`, `mc_core.pri`,
  `tests/CMakeLists.txt`, `tests/vectors/cmd.vec`, `tests/vectors/cmdd.vec`,
  `tests/core/protocol/test_commands.cpp`.
- **Acceptance criteria:**
  1. CMD-01…10 byte-for-byte from `cmd.vec`; CMD-11…14 transcribed and
     tagged `v1.1`.
  2. The QnA rows of CMDD pass from `cmdd.vec`, including odd bit counts and
     the invalid nibble (CMDD-18); CMDD-07, 08 tagged `v1.1`.
  3. VEC-02 covers both new files; `ctest -L "core_protocol|core_model|build"`
     green on MSVC.
