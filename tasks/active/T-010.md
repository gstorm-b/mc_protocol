## Plan  *(leader writes; Gate 1 approves)*

- **Goal:** Application-level conversion helpers: `include/mc/core/convert.h`
  (namespace `mc::convert`), spec §2.3, §2.4, §8.7.
- **Approach:** word/dword/float32/float64/string accessors (`*At`) and
  writers (`put*`), `packBits`/`unpackBits`, `wordsToBits`/`bitsToWords`,
  all bounds-checked (out of range returns 0/false and never reads or writes
  past the view), no allocation; the owning `from*` builders allocate
  exactly one `ByteBuf`. Word and byte order as spec §2.3 states.
- **Files expected to change:** `include/mc/core/convert.h`,
  `src/core/model/convert.cpp`, `src/CMakeLists.txt`, `mc_core.pri`,
  `tests/CMakeLists.txt`, `tests/core/model/test_convert.cpp`.
- **Acceptance criteria:**
  1. CNV-01…CNV-08 pass: D350/D351 → 170F56ABH; D0/D1 → 0.75f; "ABCD" ↔
     4241H 4443H; FFFFH → −1; float64 round trip over four words;
     `wordsToBits([1234H,0002H])` ON exactly at 2,4,5,9,12,17 (PRIM-15);
     pack/unpack round trip; out-of-range index returns 0/false.
  2. Every accessor and writer has a boundary test: the last valid index
     works, the next one returns 0/false and touches nothing.
  3. `ctest -L "core_model|build"` green.

- **Common to every Phase 1 task:**

    headers named here; "spec §N" there means
    `docs/mc_reference/mc-protocol-frame-spec.md` §N.

    listed too) **and** `mc_core.pri` in the same change (BLD-04); tests go into
    `mc_core_model_tests` (`tests/CMakeLists.txt`, label `core_model`).
  - Public headers follow `docs/rules/doc_comment_style.md`; every public
    function carries `@par Complexity` with the figures of the spec's
    "Complexity and allocation" table. No exceptions; `noexcept` as the spec
    shows. Definition of Done: `agent-team/project/definition-of-done.md`.
  - Test names start with the spec's test ID (e.g. `DEV-03 ...`).
